WordPress・バックアップ・セキュリティ

WordPress簡単インストール、簡単移行、サイトコピー、リカバリー、無料SSL、WAFなどが提供されています。自動バックアップはWeb・メールとMySQLを過去14日分保持すると案内されています。

バックアップがあることと、必要時間内に復元できることは別です。テーマ更新、プラグイン変更、移行前には自分でもファイルとデータベースを取得し、DNS、外部ストレージ、SaaS設定も別に保全します。

複数サイト・メール運用

マルチドメイン、サブドメイン、メールアカウント、FTPアカウントは無制限と案内されています。多数のサイトを置く場合は、容量だけでなくCPU・メモリ、同時処理、障害影響、権限、請求の集中を確認します。

メールではDKIM、DMARC、迷惑メール対策、転送、Webメールが利用できます。業務メールを運用する場合は、SPF/DKIM/DMARC、退職者アカウント、共有パスワード、配送ログ、Google Workspace等との併用を設計します。

契約前に確認する5項目

  • 無料お試し：通常申込みは申込日から10日間。管理画面やWordPress設置を試せます。
  • クイックスタート：WordPress新規設置・独自SSL・ドメイン取得設定をまとめて行えますが、申込みと同時に支払いが発生し、10日間無料お試しはありません。
  • ドメイン特典：スタンダードは新規12か月契約で1つ、24か月以上で2つ。プレミアム・ビジネスは2つが基本です。
  • バックアップ：Web・メールとMySQLを毎日自動保存し、過去14日分を保持します。
  • 長期契約：割引率だけでなく、契約期間分の一括支払いと更新時の通常料金を確認します。

よくある質問

エックスサーバーはいくらから使えますか？

通常36か月契約の月額換算はスタンダード990円です。2026年9月7日17:00までは36か月契約が30%オフで693円/月です。契約期間分は一括前払いです。

スタンダードとプレミアムの違いは何ですか？

スタンダードは500GB、プレミアムは600GBです。プレミアムはXwrite無料特典があり、独自ドメイン特典では.jpも選択候補になります。一般的なWordPress運用ならスタンダードから比較できます。

10日間無料お試しはありますか？

通常のサーバー申込みは10日間無料です。ただしWordPressクイックスタートは申込みと同時に支払いが発生し、無料お試し期間はありません。

独自ドメインは何個無料ですか？

新規契約ではスタンダードは12か月で1つ、24か月以上で2つ。プレミアム・ビジネスは契約期間中2つが基本です。対象TLDや取得条件は公式ページを確認してください。

バックアップは何日分ですか？

Web・メールデータとMySQLデータベースを毎日自動バックアップし、過去14日分を保持すると公式に案内されています。
