まず確認

3点でわかる要約

  1. A・B・Cは共通規格ではありません。 同じAランクでも傷の許容範囲、未使用品の扱い、D/Jランクの有無が販売店ごとに異なります。
  2. 商品ランクは主に外観の目安です。 バッテリー、保証、赤ロム、SIM/eSIM、OSサポートは別項目として確認します。
  3. 迷ったら「個体写真＋商品説明」を優先します。 ランク記号より、実際の画面・背面・角・カメラ周辺の状態が購入後の印象を左右します。
先に結論

同じ「Bランク」でも同じ状態とは限らない

中古スマホの商品ランクは、販売店が自社基準で外観や使用感を分類したものです。したがって「Aなら新品同様」「Bなら傷が少ない」と販売店をまたいで機械的に比較するのは危険です。

見た目重視S・SA・Aなど上位ランクを候補にし、個体写真も確認。
価格とのバランスB前後を中心に、画面傷と角の打痕を確認。
安さ優先C以下も候補。ただし通常利用への影響と保証条件を確認。

商品ランクを見るときの5つの確認軸

1. 画面擦り傷、爪に掛かる傷、焼き付き、白点。
2. 外装角の打痕、塗装剥がれ、ケース痕。
3. バッテリー外観ランクとは別に最大容量・劣化表示を確認。
4. 動作・保証検品項目、通常保証、赤ロム保証を確認。
5. 個体情報実機写真、商品説明、付属品、型番を確認。

A・B・Cランクは何が違う？

Aランク前後：見た目を重視する人向け

多くの販売店でAは上位の中古状態ですが、「未使用」かどうかは別です。ゲオはSを未使用、イオシスもSを新品・未使用品、ReYuuはS/SAをAより上に置いています。一方、ハピネスネットはSSを未使用、Sを新品同様としており、記号の意味が異なります。

Bランク前後：価格と状態のバランス

Bは軽い傷や使用感を許容する代わりに価格を抑えやすいゾーンです。ただし、にこスマBは1mm以下の小傷など具体的な目安を示す一方、じゃんぱらBは「比較的程度の良い中古品」としています。数文字のランクだけでなく説明文を読みます。

Cランク前後：傷を許容して価格を優先

Cは傷や使用感がより目立つ区分として使われることが多いものの、イオシスはCでも動作・機能に問題なしと案内しています。にこスマもCは外装グレードで、A〜C共通の機能検査を通過した端末を扱っています。

商品ランクとバッテリーは分けて確認する

中古スマホで特に誤解しやすいのが、外観がきれいならバッテリーも良好だろうという推測です。商品ランクは主に傷・汚れ・使用感を示し、バッテリー状態と1対1で対応しません。

  • iPhone： 最大容量表示がある販売店では個体値を優先する。
  • Android： 端末側で劣化状態を確認できない機種もあるため、販売店の検査・表記を確認する。
  • 未使用品： 未使用でも長期保管や通電確認の有無があるため、販売店定義を確認する。

特にゲオはバッテリー消耗・最大充電時の使用時間低下を経年劣化として案内しています。ランクが高いからバッテリー保証まで強いとは判断しません。

6社それぞれのランクの読み方

ゲオ：S/A/Bの3段階を中心に確認

ゲオの中古スマホはS＝未使用、A＝非常に良い、B＝良いという整理です。Bでは薄い傷、凹み、塗装剥がれ、ケース痕、カメラレンズの傷・くもりなども例示されているため、Bを「ほぼ無傷」とは考えません。

イオシス：A/B/Cの意味が明確

Aは美品、Bは良品、Cは並品。Cでも動作・機能に問題なしと案内されます。難有のDとジャンクのJはWeb販売対象外です。

ハピネスネット：SS/S/A/B/C/Jと細かい

SSを未使用、Sを新品同様、Aを程度良好、Bを傷や汚れがあるが使用可能、Cを目立つ傷や汚れがある状態として案内しています。iPhoneではバッテリー表示も同時確認しやすい点が重要です。

にこスマ：A〜Cは外装グレード

A＝超美品、B＝美品、C＝良品で、A〜C共通で機能検査を通過した商品のみを扱うと案内しています。360度写真も商品状態の確認材料になります。

ReYuu：SAランクとバッテリー別表示に注目

SとAの間にSAランクがあり、Aより状態の良いリユース商品として定義されています。商品ページではバッテリー状態が別に示されるため、外観と電池を分離して判断できます。

じゃんぱら：Dは通常利用への影響も確認

Aは状態良好、Bは比較的きれい、Cは傷がやや目立つ、Dは大きな傷などがあり一部通常利用に影響する場合があると案内しています。Dは特に個別説明を優先します。

購入前チェックリスト

  1. 販売店のランク定義を読む。
  2. 画面・背面・側面・角・カメラ周辺の個体写真を見る。
  3. バッテリー状態をランクとは別に確認する。
  4. 同じ機種でもキャリア型番・SIM/eSIM・おサイフケータイ等を確認する。
  5. 通常保証と赤ロム保証を確認する。
  6. 同一型番・容量・状態で現在価格を比較する。

購入先そのものを比較したい場合は、中古スマホ購入先6社比較、iPhoneは中古iPhone購入先比較、Androidは中古Android購入先比較も合わせて確認できます。

よくある質問

中古スマホのAランクは販売店が違っても同じ品質ですか？

同じではありません。A・B・Cなどの記号は業界共通規格ではなく、販売店ごとに定義が異なります。

Bランクの中古スマホは買っても大丈夫ですか？

Bでも傷や使用感の基準が異なります。外観だけでなく、動作検査、保証、バッテリー、ネットワーク利用制限、個体写真まで確認してください。

商品ランクが高ければバッテリーも良好ですか？

必ずしも一致しません。多くの販売店では商品ランクは主に外装状態を表すため、バッテリーは個別の表示や検査条件を確認します。

CランクやDランクは避けた方がいいですか？

外観を気にしない場合は価格面で候補になります。ただしD/J等は難有・ジャンクや通常利用への影響を含む場合があるため、メイン端末では特に慎重に確認します。

記事内の価格確認リンクはアフィリエイトですか？

2026年8月11日時点では6社の価格確認ボタンは公式サイトへのリンクです。提携承認後に広告リンクへ切り替える場合は、広告であることが分かる表示を維持します。
