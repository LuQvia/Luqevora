申請と発注を混ぜない

東京観光財団は代行申請を受け付けておらず、発注予定先企業等が申請書類の作成や相見積書の取得まで代行した事実が判明した場合は交付対象外と案内しています。サービス事業者には仕様・見積・必要情報の提供を依頼し、申請主体は店舗側で管理します。

公開前・設置前の確認

多言語ページはメニュー、価格、アレルギー、営業時間、予約、決済、アクセスを実機で確認します。サイネージは設置場所、電源、表示内容、更新方法を確認し、補助対象として申請した内容と実際の導入内容がずれないよう記録を残します。

運用ルール

翻訳・メニュー・価格・営業時間・口コミ返信・サイネージ表示を誰が更新するか決めます。導入後の保守費や更新費が補助対象外でも継続できるかを、年間総額で確認します。

効果測定

導入前の外国語ページ閲覧数、予約数、外国語問い合わせ、口コミ件数、キャッシュレス比率などを保存し、30日・90日で比較します。補助金の採択自体ではなく、来店・注文・業務効率の改善を成果指標にします。
